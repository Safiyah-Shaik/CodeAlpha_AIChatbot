# 🤖 CodeAlpha AI Chatbot

A Java-based Artificial Intelligence Chatbot developed as part of the **CodeAlpha Java Programming Internship**.

The chatbot provides interactive, real-time responses using **rule-based processing and NLP-style text preprocessing**, with a professional web interface.

## ✨ Features

* 🤖 Java-powered chatbot
* 🧠 Rule-based AI response system
* 📝 NLP-style text preprocessing
* 💬 Real-time chat interaction
* ☕ Java programming FAQs
* 📚 OOP, AI, Machine Learning and NLP concepts
* ⚡ Quick question buttons
* ⌨️ Enter-key message support
* 📱 Responsive web interface
* 🔄 Typing indicator for better user experience

## 🛠️ Technologies Used

* **Java**
* **Spring Boot**
* **Spring Web**
* **HTML5**
* **CSS3**
* **JavaScript**
* **Maven**

## 🧠 Chatbot Capabilities

The chatbot can answer questions related to:

* Java
* Object-Oriented Programming
* Classes and Objects
* Inheritance
* Polymorphism
* Encapsulation
* Abstraction
* Arrays
* Artificial Intelligence
* Machine Learning
* Natural Language Processing

## 🔍 NLP Processing

The chatbot performs basic NLP-style preprocessing before generating responses:

1. Converts user input to lowercase.
2. Removes unnecessary special characters.
3. Normalizes extra spaces.
4. Identifies keywords and patterns.
5. Generates an appropriate rule-based response.

## ▶️ How to Run

Make sure Java and Maven are installed.

### Using Maven Wrapper

```bash
./mvnw spring-boot:run
```

Then open:

```text
http://localhost:8080
```
